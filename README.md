# Strategic Data Science Research Series

This repository contains a series of automated data analysis projects designed to transform raw data into professional strategic reports (PDF & DOCX).

## Project 2: Automotive Strategic Dashboard
**Focus:** Economic Crisis Impact Analysis (2019-2023)

### Overview
An analytical platform that studies the resilience of the automotive market. It compares the performance of **Electric Vehicles (EV)** vs. **Internal Combustion Engines (ICE)** during global economic downturns.

### Key Features
- **Synthetic Data Generation:** Simulates 5 years of sales data with crisis variables.
- **Automated Visualization:** Generates trend lines and impact bar charts.
- **Strategic Reporting:** Automatically compiles findings into professional PDF and Word documents.

## Project 1: SpaceX Falcon 9 Landing Success
**Focus:** Predictive Factors in Aerospace Engineering

### Overview
A data-driven study focused on identifying the variables that influence the successful landing of Falcon 9 boosters, such as payload mass and orbit types.

### Technologies Used
- **Language:** Python
- **Libraries:** Pandas, Matplotlib, Seaborn
- **Documentation:** Python-docx, FPDF2
- **Automation:** Orchestration scripts (`run_all.py`)
